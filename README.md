
# UC09 · Desenvolver Algoritmos com Python

Repositório de apoio da Unidade Curricular 09 – Desenvolver Algoritmos.

Este espaço reúne os exemplos desenvolvidos em aula, listas de exercícios e materiais complementares utilizados ao longo da disciplina.

---

## 📂 Estrutura do Repositório

Os arquivos principais estão organizados da seguinte forma:

### 🐍 Arquivos `.py` (raiz do projeto)

Os arquivos numerados representam a progressão do conteúdo trabalhado em aula.

Exemplos:

```

000-olamundo.py
001-variaveis.py
004-operadores.py
007-loop.py
012-dicionarios.py
014-exemplo-dic2.py

```

A numeração indica a ordem recomendada de estudo.

---

### 📁 notebooks/

Contém listas de exercícios e resoluções no formato Jupyter Notebook.

```

notebooks/
├── lista-00-exercicios.ipynb
├── lista-01-resolucao.ipynb
└── lista-02-resolucao.ipynb

```

Utilizado para prática guiada e resolução comentada.

---

### 📁 recursos/

Materiais complementares em PDF:

- Conteúdos teóricos
- Listas de exercícios (enunciados)
- Livro de apoio

Exemplo:

```

recursos/
├── 01-Conteudo.pdf
├── 02-Lista-de-Exercicios 1.pdf
├── Livro_Curso_Intensivo_de_Python.pdf

````

---

## ▶ Como executar os arquivos

1. Instale o Python (3.10 ou superior recomendado):  
https://www.python.org/downloads/

2. Clone o repositório:

```bash
git clone https://github.com/wesscosta/uc09-desenvolver-algoritimos.git
cd uc09-desenvolver-algoritimos
````

3. Execute um exemplo:

```bash
python 000-olamundo.py
```
